PROYECTO FACTURAS - COMANDOS DEL PROYECTO
=========================================

Este archivo contiene únicamente comandos propios de ProyectoFacturas.
Para Git, entornos virtuales, pip, pytest y PowerShell consultar DEV_COMMANDS.txt.

Ejecutar los comandos desde la carpeta raíz del proyecto.


1. AYUDA
--------

Ver todos los comandos disponibles:

    python main.py --help

Versión corta:

    python main.py -h


2. EJECUCIÓN NORMAL / GMAIL
---------------------------

    python main.py

Se conecta a Gmail, revisa la cantidad de correos definida mediante
EMAIL_PROCESSING_LIMIT, omite los ya completados, descarga PDFs y los pasa por
el pipeline de clasificación, parsing y organización.


3. ESCANEO COMPLETO DE GMAIL
----------------------------

    python main.py --full-scan

Recorre todo el historial de Gmail desde el más reciente al más antiguo y omite
los mensajes ya completados. El progreso queda registrado en el historial local.


4. REPROCESAR DOCUMENTOS PENDIENTES
-----------------------------------

    python main.py --reprocess-pending

Analiza nuevamente los PDFs de Facturas/_Pendientes sin conectarse a Gmail.
Puede organizar facturas o archivar otros documentos cuando la evidencia sea
suficiente y no ambigua.


5. NORMALIZAR CARPETAS DE PROVEEDORES
-------------------------------------

    python main.py --normalize-supplier-folders

Reúne carpetas históricas que representan al mismo proveedor. No sobrescribe
archivos distintos.


6. BUSCAR Y ELIMINAR DUPLICADOS
-------------------------------

Vista previa segura:

    python main.py --deduplicate-invoices

Aplicar la limpieza confirmada:

    python main.py --deduplicate-invoices --apply

La deduplicación compara contenido mediante hash y solo elimina copias idénticas.


7. AUDITAR FECHAS DE FACTURAS ORGANIZADAS
-----------------------------------------

Vista previa:

    python main.py --audit-organized-dates

Aplicar correcciones:

    python main.py --audit-organized-dates --apply

Revisa si la fecha detectada en el PDF coincide con la carpeta y el nombre del
archivo. No reemplaza archivos existentes.


8. HISTORIAL DE CORREOS
-----------------------

Mostrar resumen:

    python main.py --email-history

Vista previa del reinicio:

    python main.py --reset-email-history

Reiniciar realmente:

    python main.py --reset-email-history --apply

ADVERTENCIA: al reiniciar el historial, los correos vuelven a considerarse no
procesados. La base local se guarda por defecto en:

    <proyecto>/data/project_state.sqlite3

Para reconstruir Facturas desde cero:

    1. python main.py --reset-email-history
    2. python main.py --reset-email-history --apply
    3. Respaldar o eliminar manualmente la carpeta Facturas.
    4. python main.py --full-scan


9. EXPORTAR PERFIL IMPOSITIVO DE PROVEEDORES
--------------------------------------------

    python main.py --export-supplier-tax-profile

Recorre las facturas organizadas y genera en el Escritorio:

    Perfil_Impositivo_Proveedores_AAAA-MM-DD.xlsx

El reporte agrupa por CUIT e indica los impuestos observados sin mostrar importes.


10. ACTUALIZAR CATÁLOGO DE PROVEEDORES DESDE AFIP/ARCA
------------------------------------------------------

Importar desde un Excel de comprobantes recibidos:

    python tools/import_afip_suppliers.py "C:\ruta\Mis Comprobantes Recibidos.xlsx"

Cambiar el mínimo de apariciones requerido:

    python tools/import_afip_suppliers.py "C:\ruta\archivo.xlsx" --min-occurrences 3

El catálogo utilizado por el proyecto queda en:

    suppliers/data/supplier_catalog.json

Después de actualizarlo es recomendable ejecutar las pruebas y luego reprocesar
los pendientes. Los comandos generales de pruebas están en DEV_COMMANDS.txt.


11. ARCHIVOS Y CONFIGURACIÓN IMPORTANTES
----------------------------------------

Configuración local:

    .env

Plantilla de configuración:

    .env.example

Historial local:

    data/project_state.sqlite3

Logs (si LOG_FOLDER no define otra ubicación):

    logs/YYYY-MM-DD.log

Catálogo de proveedores:

    suppliers/data/supplier_catalog.json


12. OPERACIONES DESTRUCTIVAS
----------------------------

Los comandos que pueden modificar/eliminar información de forma sensible usan
--apply cuando corresponde. Conviene ejecutar primero la vista previa:

    python main.py --deduplicate-invoices
    python main.py --audit-organized-dates
    python main.py --reset-email-history

Y solo después, si el resultado es correcto, repetir con --apply.
